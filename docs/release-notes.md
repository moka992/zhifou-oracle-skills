## Zhifou Oracle Skills 0.1.0

**Draw locally. Interpret thoughtfully.**

A standalone Agent Skill for I Ching, Rider-Waite-Smith tarot, and original reflection cards. It separates fixed outcomes and source material from model-written interpretation.

### Included

- 64 hexagrams, 384 line texts, classical context, and an explicit changing-line policy.
- All 78 historical RWS card fronts and modern Chinese reference summaries; single, three-card, and ten-card spreads.
- 100 original reflection entries.
- Python-standard-library local tools, imported-result preservation, receipt verification, and a self-contained skill ZIP.
- English / 简体中文 documentation, concise runtime prompts, and Android prompt export.
- Deterministic regressions, including all 4,096 six-line value combinations, plus separate behavioral evaluation fixtures.

### Install

Download `zhifou-oracle-0.1.0.zip` and unpack the `zhifou-oracle/` folder into your host's skills location, or use the project installer from the repository. The `.sha256` file allows download integrity checking.

Code and original writing are MIT; the adapted Kanseki Zhou Yi data remains CC BY-SA 4.0; historical artwork retains source notices. Local tools require no API key. A host model may still require a subscription or paid API.
